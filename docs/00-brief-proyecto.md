# Brief del proyecto

## Escenario

Equipo 6: Abarrotes.

## Problema

Un negocio de abarrotes necesita controlar productos, existencias, proveedores, clientes, ventas y corte de caja. El sistema debe permitir consultar y registrar operaciones de forma clara, validada y útil para una demostración en clase.

## Alcance mínimo obligatorio

1. Inventario.
2. Clientes.
3. Proveedores.
4. Ventas.
5. Corte de caja.
6. Catálogo de usuarios.
7. 30 registros cargados antes de la entrega.

## Criterios de éxito

- El programa funcióna correctamente durante la demo.
- Las entradas están validadas.
- La interfaz es fácil de usar y entender.
- El diseño es claro y estructurado.
- El sistema resuelve el caso de uso de un abarrotes real.
- La documentación y presentación explican el problema, la implementación, los problemas encontrados y las conclusiones.
