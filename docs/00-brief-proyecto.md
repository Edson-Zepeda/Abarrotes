# Brief del proyecto

## Escenario

Equipo 6: Abarrotes.

## Problema

Un negocio de abarrotes necesita controlar productos, existencias, proveedores, clientes, ventas y corte de caja. El sistema debe permitir consultar y registrar operaciones de forma clara, validada y util para una demostracion en clase.

## Alcance minimo obligatorio

1. Inventario.
2. Clientes.
3. Proveedores.
4. Ventas.
5. Corte de caja.
6. Catalogo de usuarios.
7. 30 registros cargados antes de la entrega.

## Criterios de exito

- El programa funciona correctamente durante la demo.
- Las entradas estan validadas.
- La interfaz es facil de usar y entender.
- El diseno es claro y estructurado.
- El sistema resuelve el caso de uso de un abarrotes real.
- La documentacion y presentacion explican el problema, la implementacion, los problemas encontrados y las conclusiones.
