# Backlog del producto

## Prioridad alta

- Crear menú principal.
- Crear catálogo de usuarios.
- Crear inventario de productos.
- Registrar clientes.
- Registrar proveedores.
- Registrar ventas.
- Calcular corte de caja.
- Cargar 30 registros iniciales.
- Validar entradas numéricas, textos vacíos y existencias insuficientes.

## Prioridad media

- Búsqueda de productos por nombre o código.
- Historial de ventas.
- Resumen de productos con bajo inventario.
- Confirmación antes de operaciones importantes.

## Prioridad baja

- Exportar resumen a archivo.
- Mejorar formato visual de tablas.
- Agregar roles de usuario.
- Agregar pantalla de ayuda.

## Definición de terminado

Una tarea se considera terminada cuando:

- Compila sin errores.
- Se puede demostrar en menos de 2 minutos.
- Tiene validaciones básicas.
- No rompe otro flujo del sistema.
- Está documentada con una captura o explicación breve para el reporte.
