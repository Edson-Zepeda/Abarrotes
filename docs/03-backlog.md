# Backlog del producto

## Prioridad alta

- Crear menu principal.
- Crear catalogo de usuarios.
- Crear inventario de productos.
- Registrar clientes.
- Registrar proveedores.
- Registrar compras.
- Registrar ventas.
- Calcular corte de caja.
- Cargar 30 registros iniciales.
- Validar entradas numericas, textos vacios y existencias insuficientes.

## Prioridad media

- Busqueda de productos por nombre o codigo.
- Historial de compras.
- Historial de ventas.
- Resumen de productos con bajo inventario.
- Confirmacion antes de operaciones importantes.

## Prioridad baja

- Exportar resumen a archivo.
- Mejorar formato visual de tablas.
- Agregar roles de usuario.
- Agregar pantalla de ayuda.

## Definicion de terminado

Una tarea se considera terminada cuando:

- Compila sin errores.
- Se puede demostrar en menos de 2 minutos.
- Tiene validaciones basicas.
- No rompe otro flujo del sistema.
- Esta documentada con una captura o explicacion breve para el reporte.
